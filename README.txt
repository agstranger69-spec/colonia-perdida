COLONIA PERDIDA - VERSION ACTUALIZABLE

Archivos principales:
- index.html: juego
- manifest.webmanifest: instalación como PWA
- sw.js: caché/offline y actualización de recursos
- icon-192.png / icon-512.png: iconos
- version.json: versión actual

Para actualizar el juego en el futuro, reemplazar index.html (y version.json si cambia la versión) en el mismo servidor. No hace falta cambiar la URL.

Recomendado: publicar esta carpeta con GitHub Pages o cualquier hosting HTTPS.
